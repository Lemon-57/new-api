# Connecting ezpay

In **System Settings → Billing → Epay**, enter the ezpay base URL and the merchant PID and key. Select **ezpay (MD5)**. This mode sends the standard MD5 signature without the `device` field, and explicitly signs the order currency as `CNY` so the ezpay merchant's default currency cannot reinterpret a recharge amount. Users can still pay in a different currency through enabled ezpay channels. New API checks the signed original amount and currency before accepting a paid notification; the converted amount does not change the credited quota.

Keep the `alipay` payment method enabled for the existing direct Alipay configuration. Add an independent method with `type: epay_alipay` and a label such as `支付宝（ezpay）`; New API sends it as `alipay` to the Epay gateway. Add only payment methods that are enabled for the merchant in ezpay, such as `wxpay` or `usdt_trc20`. Each method uses the same configured Epay merchant. Direct Alipay retains its own credentials and callback.

Make the New API callbacks reachable from ezpay: `/api/user/epay/notify` for top-ups and `/api/subscription/epay/notify` for subscriptions (which use the New API plan price in `USD`). The ezpay merchant must be allowed to use the selected payment channels. Before switching a live Epay merchant, reconcile its pending orders, preserve the existing direct Alipay configuration, and test each enabled channel with a small order. Check the checkout currency and amount, notification, and exactly one balance credit; do not treat an order page or a browser redirect as proof of settlement.
